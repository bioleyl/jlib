# jlib: notes for working on the code

Before writing code, look at the skills in `~/.agents/skills` and in the project's `.agents/skills` (a `SKILL.md` in
each folder) and load those that fit the task, `jadis-official` (the frontend library) first: Claude Code does not
find them there by itself. Of two skills of one name, the one in `~/.agents/skills` wins. If `jadis-official` is in
neither, install it with `npx skills add bioleyl/jadis --agent universal --yes`.

The project's notes are in `AGENTS.md`, which other coding agents read too: add to them there, not here.
